# איפה בטוח? — גרסה 9.0.0

אפליקציית רשת לטלפון, בלי התקנה חוזרת של חבילת מסלולים כבדה.

## ארכיטקטורה
- אתר סטטי עם Service Worker והתקנה למסך הבית.
- `data/catalog.json` אינדקס קווים ותחנות; `data/line/<number>.json` תוואים רשמיים נטענים לפי קו בלבד.
- בקשה ל־`data/version.json` בכל פתיחה; קובצי מידע נשמרים במטמון תחת מזהה גרסה.
- `build_catalog.py` מעדכן את כל הקווים מארכיון GTFS הרשמי, ולא ממפה מומצאת.
- מיקומי זמן־אמת מבוססי SIRI: ללא אישור גישה וזמן מדידה טרי, יוצגו נתונים כלא מאומתים.

## הפעלה אוטומטית
האתר מתפרסם בענף `eifo-batuach-site`. קובץ GitHub Actions הנמצא ב־`.github/workflows/eifo-batuach.yml` בענף הראשי מוריד את המידע הרשמי מדי יום ופורס אותו לאתר באמצעות GitHub Pages. צריך להפעיל ב־Settings → Pages את GitHub Actions בתור מקור הפרסום, אחרת העבודה תיכשל בשלב ההעלאה.

## מגבלות
- לא אומתה גישה חיה ל־SIRI מתוך הטלפון. הפעלת אתר אינה שווה לאימות הנתונים.
- האתר ציבורי, ולכן אין להכניס מפתחות API פרטיים למאגר.
- הנתונים הסטטיים מגיעים ממשרד התחבורה, אך גם בהם עשויות להיות שגיאות; גרסאות נבדקות לפני פרסום.
- במקרי CORS יש צורך במתווך ענן שדורש פריסה חד־פעמית בחשבון המשתמש.
