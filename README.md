# איפה בטוח? — DEV-9.1.3

אפליקציית רשת לטלפון, בלי התקנה חוזרת של חבילת מסלולים כבדה.

## ארכיטקטורה
- אתר סטטי עם Service Worker והתקנה למסך הבית.
- `data/catalog.json` אינדקס קווים ותחנות; `data/line/<number>.json` תוואים רשמיים נטענים לפי קו בלבד.
- בקשה ל־`data/version.json` בכל פתיחה; קובצי מידע נשמרים במטמון תחת מזהה גרסה.
- `build_catalog.py` מעדכן את כל הקווים מארכיון GTFS הרשמי, ולא ממפה מומצאת.
- מיקומי זמן־אמת מבוססי SIRI: ללא אישור גישה וזמן מדידה טרי, יוצגו נתונים כלא מאומתים.

## הפעלה אוטומטית
האתר מתפרסם בענף `eifo-batuach-site`. קובץ GitHub Actions הנמצא ב־`.github/workflows/eifo-batuach.yml` בענף הראשי מוריד את המידע הרשמי מדי יום ופורס אותו לאתר באמצעות GitHub Pages. צריך להפעיל ב־Settings → Pages את GitHub Actions בתור מקור הפרסום, אחרת העבודה תיכשל בשלב ההעלאה.

## מגבלות
- חיבור DEV ל־LIVE-WORK אומת בדפדפן וב־HTTPS. דיווח חי מוצג רק כשהזהות וחותמות הדיווח תקינות; אין בכך אימות GPS עצמאי או הבטחת דיווח לכל נסיעה.
- האתר ציבורי, ולכן אין להכניס מפתחות API פרטיים למאגר.
- הנתונים הסטטיים מגיעים ממשרד התחבורה, אך גם בהם עשויות להיות שגיאות; גרסאות נבדקות לפני פרסום.
- במקרי CORS יש צורך במתווך ענן שדורש פריסה חד־פעמית בחשבון המשתמש.

## תיקוני אמינות 9.0.4
- זיהוי SIRI לפי מזהה route_id הרשמי, לא לפי ניחוש ב-route_desc.
- אם מקור אחד מחזיר רשימה ריקה, נבדקים שאר המקורות. רשימה ריקה אינה הוכחה שהאוטובוס לא יצא.
- לאחר כשל תקשורת, זמני הגעה קודמים אינם מוצגים כדיווח עדכני.
- בדיקות יחידה של זהות מסלול, מעבר בין מקורות וחוסר מידע לפני בדיקת דפדפן.
- שרת מתווך מאובטח לדוגמה נמצא ב-backend/cloudflare-worker.mjs; **קוד השרת לבדו אינו פורס אותו**. יש לפרוס על חשבון שרת מאושר ולהזין את הכתובת בהגדרות. היישומון עדיין לא מספק תחזיות חיות מאומתות בלי מקור נגיש.

## 9.0.5 — תנועה והיסטוריית רכבים
- `vehicle-history.js`: תצפיות GPS בעלות מזהה רכב יציב נשמרות מקומית לתקופה מוגבלת; עצירות ממושכות בנסיעות שונות עשויות לגרור סימון אזהרה זהיר. שיבושי קליטה אינם נחשבים הוכחה לתקלה.
- `traffic-analysis.js`: חוזה נתוני תנועה עם קטעי דרך גאוגרפיים, מהירויות, רמת אמינות וחותמת זמן. `SafeBusApp.applyTrafficSnapshot(snapshot)` מחבר נתוני שרת עתידיים למפה, אך לא מושך אותם בעצמו.
- בגרסה הישנה הוצעה שכבת TomTom באמצעות מפתח בדפדפן; אפשרות זו הוסרה ב־DEV-9.1.3. צבעי כביש אינם משמשים לתיקון תחזית, ואין תוספת ללוח זמנים רגיל או לתחזית חיה.
- שיפורים אלה אינם מתקנים בפני עצמם את החיבור לנתונים חיים; פיתוח השרת נעשה בענף `work/live-data-20261009` בנפרד.

- לא שונו main, eifo-batuach-site או work/live-data-20261009; PR 3 משמש מקור חוזה בלבד ואינו ממוזג.
