# איפה בטוח? — DEV-9.1.8

אפליקציית רשת לטלפון, בלי התקנה חוזרת של חבילת מסלולים כבדה.

## ארכיטקטורה
- אתר סטטי עם Service Worker והתקנה למסך הבית.
- `data/catalog.json` אינדקס קווים ותחנות; `data/line/<number>.json` תוואים רשמיים נטענים לפי קו בלבד.
- בקשה ל־`data/version.json` בכל פתיחה; קובצי מידע נשמרים במטמון תחת מזהה גרסה.
- `build_catalog.py` מעדכן את כל הקווים מארכיון GTFS הרשמי, ולא ממפה מומצאת.
- מיקומי זמן־אמת מבוססי SIRI: ללא אישור גישה וזמן מדידה טרי, יוצגו נתונים כלא מאומתים.

## הפעלה אוטומטית
האתר מתפרסם בענף `eifo-batuach-site`. קובץ GitHub Actions הנמצא ב־`.github/workflows/eifo-batuach.yml` בענף הראשי מוריד את המידע הרשמי מדי יום ופורס אותו לאתר באמצעות GitHub Pages. צריך להפעיל ב־Settings → Pages את GitHub Actions בתור מקור הפרסום, אחרת העבודה תיכשל בשלב ההעלאה.

## מגבלות
- חיבור DEV ל־LIVE-WORK אומת בדפדפן וב־HTTPS. דיווח חי מוצג רק כשהזהות וחותמות הדיווח תקינות; אין בכך אימות GPS עצמאי או הבטחת דיווח לכל נסיעה.
- האתר ציבורי, ולכן אין להכניס מפתחות API פרטיים למאגר.
- הנתונים הסטטיים מגיעים ממשרד התחבורה, אך גם בהם עשויות להיות שגיאות; גרסאות נבדקות לפני פרסום.
- במקרי CORS יש צורך במתווך ענן שדורש פריסה חד־פעמית בחשבון המשתמש.

## תיקוני אמינות 9.0.4
- זיהוי SIRI לפי מזהה route_id הרשמי, לא לפי ניחוש ב-route_desc.
- אם מקור אחד מחזיר רשימה ריקה, נבדקים שאר המקורות. רשימה ריקה אינה הוכחה שהאוטובוס לא יצא.
- לאחר כשל תקשורת, זמני הגעה קודמים אינם מוצגים כדיווח עדכני.
- בדיקות יחידה של זהות מסלול, מעבר בין מקורות וחוסר מידע לפני בדיקת דפדפן.
- שרת מתווך מאובטח לדוגמה נמצא ב-backend/cloudflare-worker.mjs; **קוד השרת לבדו אינו פורס אותו**. יש לפרוס על חשבון שרת מאושר ולהזין את הכתובת בהגדרות. היישומון עדיין לא מספק תחזיות חיות מאומתות בלי מקור נגיש.

## 9.0.5 — תנועה והיסטוריית רכבים
- `vehicle-history.js`: תצפיות GPS בעלות מזהה רכב יציב נשמרות מקומית לתקופה מוגבלת; עצירות ממושכות בנסיעות שונות עשויות לגרור סימון אזהרה זהיר. שיבושי קליטה אינם נחשבים הוכחה לתקלה.
- `traffic-analysis.js`: חוזה נתוני תנועה עם קטעי דרך גאוגרפיים, מהירויות, רמת אמינות וחותמת זמן. `SafeBusApp.applyTrafficSnapshot(snapshot)` מחבר נתוני שרת עתידיים למפה, אך לא מושך אותם בעצמו.
- בגרסה הישנה הוצעה שכבת TomTom באמצעות מפתח בדפדפן; אפשרות זו הוסרה ב־DEV-9.1.3. צבעי כביש אינם משמשים לתיקון תחזית, ואין תוספת ללוח זמנים רגיל או לתחזית חיה.
- שיפורים אלה אינם מתקנים בפני עצמם את החיבור לנתונים חיים; פיתוח השרת נעשה בענף `work/live-data-20261009` בנפרד.

## DEV-9.1.3 — שילוב חוזה Work בלי מיזוג ענפים
- גישה להיסטוריה לפי רכב ומפעיל דרך שרת DEV, עם חלון קבוע לדפדוף ורשומות שיוך מתוכנן בנפרד מדיווחי מיקום.
- תשובה חלקית ופסק זמן מוצגים בגלוי; מזהי מסלול במקור אינם מוצגים כמספרי קווים ציבוריים או כהוכחה לכשל.
- ארכיון SIRI אינו מקבל תווית מדידת GPS. היסטוריית עצירות מקומית משתמשת במרחב מזהים לפי מפעיל ורכב ובמדידות בעלות חותמת GPS עצמאית בלבד; לא נעשה שימוש בהיסטוריה ישנה שסווגה ללא ראיה זו.
- תנועה אינה מופעלת ואין מפתח בדפדפן. קטעי מהירות ישנים, model data ברמת confidence עד 0.70 וחוסר live נדחים. שכבות פגות תוקף אחרי 180 שניות. אין תוספת גנרית ללוח זמנים או לתחזית SIRI; חישוב עתידי מחייב etaDecision מפורש ובסיס זרימה חופשית מאומת.
- לא שונו main, eifo-batuach-site או work/live-data-20261009; PR 3 משמש מקור חוזה בלבד ואינו ממוזג.

## DEV-9.1.4 — תצוגת מוצר ברורה
- מפה ברוחב המסך במחשב, סרגל קו ותחנה לצד המפה וסמלי אוטובוסים ממשיים עם גיל הדיווח. רכב אינו מונפש בין דיווחים.
- רשימת האוטובוסים וכפתור מרכז על אוטובוסים משתמשים רק ברכבים שמוצגים במפה. מידע חסר מוסבר במפורש.
- traffic.html מציג בנפרד את ה־iframe הרשמי של Waze. אין חילוץ נתוני Waze למפת האוטובוסים, אין מפתח API חדש ואין תיקון ETA מתוך מפה זו. https://developers.google.com/waze/iframe
- מדיניות תוכן מגבילה סקריפטים למקור האתר ומאפשרת רק את iframe התנועה הרשמי. ההגדרות נגישות במקלדת.

## DEV-9.1.5 — גישה ישירה למפת פקקים
- נוסף קישור לפי התחנה ל־Google Maps URLs עם layer=traffic. זהו קישור צרכני רשמי ללא מפתח API; אין חילוץ נתונים ואין שינוי לזמני ההגעה. https://developers.google.com/maps/documentation/urls/get-started
- קישור למפות המלאות זמין גם כאשר ספק ההטמעה אינו מחזיר את כל נתוני התנועה. הודעת תחזית ריקה מנצלת את רוחב סרגל התוצאות.

## DEV-9.1.8 — מפה ארצית וחיפוש
- פתיחה ארצית ללא בחירת גילה. תחנות מאוגדות במפה לפי גודל התצוגה; בחירת תחנה מציגה את כל הקווים, דיווחים וזמני הגעה מאומתים.
- חיפוש תחנות מקומי; חיפוש כתובת נשלח רק בלחיצה ל־Photon/OSM, עם מטמון, גבולות ישראל ומענה לשגיאות ספק.
- API dataset קורא את פרסום GTFS הקיים כדי לפתוח עם נתונים עדכניים בלי שינוי ענף הפרסום. API national משתמש בחוזה הנרמול שנבדק ב־WORK, בעותק DEV נפרד, ובודק מקור SIRI וחתימות זמן.
- מיקומים אזוריים מארכיון הסדנה מתקבלים רק כאשר זמן הדיווח וזמן snapshot טריים. תאריכים עתידיים וצילומים ישנים נפסלים. fallback בודק שלוש תחנות סמוכות; הכיסוי החלקי מסומן ואינו מוצג ככל צי האוטובוסים.
- שכבת TomTom מוכנה על אותה מפת Leaflet. כדי להפעילה נדרשים TOMTOM_TRAFFIC_KEY, TOMTOM_TRAFFIC_ENABLED=true ו־TOMTOM_NONBILLING_CONFIRMED=true לאחר הרשאה וזכאות ללא חיוב. המפתח נשאר בשרת. אין שינוי ETA ואין צבעי פקק מומצאים.
- המסך מנצל את כל השטח, פרטי התחנה בגודל התוכן, ושכבות/קווים/כיוון נבחרים בלי מעבר למפה אחרת.
- בדיקות national_contract ו־dev_national_browser מפרידות קריאות כתובת/תחנה אמיתיות ממקרי UI סינתטיים המסומנים בשם תמונת הבדיקה.
